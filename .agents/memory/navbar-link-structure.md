---
name: Storefront navbar link structure
description: Current top-level nav structure and dropdown groupings, for consistency when adding new links
---

Nav order: Home | Shop (dropdown) | Customize (marked "NEW") | Help (dropdown) | Company (dropdown).

- `HELP_LINKS`: FAQ, Size Guide, Track Order, Return Policy, Contact.
- `COMPANY_LINKS`: About, Blog, Referral, Terms, Privacy.
- Gift Hampers lives inside the Shop dropdown, not as its own top-level item.

**How to apply:** when adding a new customer-facing page, place it in the Help or Company dropdown by nature (support-related vs. company-related) rather than adding new top-level nav items.
