# GLB Models Missing

The `artifacts/trynex-storefront/public/models/` directory is empty.
No GLB files (tshirt.glb, hoodie.glb, longsleeve.glb, cap.glb) exist.

## What was broken
- `RealisticShirt` in garment3d.tsx called `useGLTF("/models/tshirt.glb")` — crash
- `LongSleeveBody` called `GarmentGLB` with `/models/longsleeve.glb` — crash
- `HoodieBody` called `GarmentGLB` with `/models/hoodie.glb` — crash
- `CapBody` called `useGLTF("/models/cap.glb")` — crash
- All four had eager `useGLTF.preload()` calls at module import — crashed on any page

## Fix applied
All four `useGLTF.preload()` calls commented out in `garment3d.tsx`.
In both `ProductViewer3D.tsx` and `CartViewer3D.tsx`, replaced with `PhotoMockupMesh`:
- T-shirt → `PhotoMockupMesh` using white-tshirt-front-cutout.png + back-cutout.png
- Hoodie → `PhotoMockupMesh` using white-hoodie-front-cutout.png + back-cutout.png
- Long sleeve → `PhotoMockupMesh` using white-longsleeve-front-cutout.png + back-cutout.png
- Cap → `PhotoMockupMesh` using white-cap-front-cutout.png (no back)

`MugBody` and `WaterBottleBody` are procedural Three.js geometry — still used in CartViewer3D (no GLB).

**Why:** GLBs were generated by a now-missing script (`scripts/generate-models.cjs`). They were never committed to the repo.

**How to apply:** If GLBs are ever regenerated and committed, revert ProductViewer3D.tsx and CartViewer3D.tsx to use the original components and un-comment the preload calls.
