Rendering Pipeline

White/Light garments: Transparent-BG cutout PNG + subtle SVG drop-shadow. No tint applied — garment renders in its natural colour.

Coloured garments: Cutout PNG + SVG multiply-tint filter (desaturate → flood colour → composite with alpha → blend with grey).

Near-black garments: Dedicated black photo cutout used directly — superior quality vs. tint filter on dark fabric.

Cylinder products (Mug, Bottle): feDisplacementMap barrel warp + product-silhouette clip path prevents design overflow outside the product body.

Bugs Fixed This Session

  • Hoodie front cutout was 896×1280 (wrong dimensions causing misalignment) — switched to correct 1000×1000 version
  • Long sleeve had no dark photo variants — generated black longsleeve front/back + cutout PNGs via ImageMagick and wired into BASE_BY_CATEGORY
  • Mug and water bottle designs could visually overflow outside the product body — added product-silhouette clipPath and nested clip groups
  • Longsleeve cutouts switched to higher-quality -new versions for better colour accuracy

Infrastructure

Database

Neon PostgreSQL (serverless) with Drizzle ORM. Full schema: users, products, orders, promos, reviews, blog, sessions, admin.

Cache

Upstash Redis for distributed caching. Auto-detects connection and enables MISS→HIT cache for products, settings, stats.

Storage

Replit Object Storage for user uploads (design images, product photos). Fallback to disk for dev.

Scheduler

In-process scheduler: keep-alive pings, abandoned cart emails, cache TTL management.
